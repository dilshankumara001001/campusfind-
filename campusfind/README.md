# 🎓 CampusFind - Lost & Found Campus System

## Features
- Item Reporting (Lost/Found)
- Smart Matching Algorithm (85%+ accuracy)
- Claim System with Approval Workflow
- Real-time Notifications
- Admin Dashboard
- Responsive Design

## Installation
1. Import `database/database.sql` to MySQL
2. Update `config/database.php` with your credentials
3. Start XAMPP/WAMP
4. Access: http://localhost/campusfind/
