> University Lost & Found Management System with Smart Matching

---

## 📌 About

CampusFind is a web application for university students and staff to report lost or found items. The system automatically matches lost items with found ones using smart algorithms.

---

## ✨ Features

- 🔐 **Login/Register** - Secure authentication
- 📱 **Report Items** - Lost or found with images
- 🎯 **Smart Matching** - Auto-match items (85%+ accuracy)
- 📩 **Claim System** - Submit and manage claims
- 🔔 **Notifications** - Real-time alerts
- 👨‍💼 **Admin Panel** - Full system control
- 📱 **Responsive** - Works on all devices
